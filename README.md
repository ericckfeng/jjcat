# 飲控隨身記

用手機隨手記錄三餐，產生報告和營養師一起討論的網頁 App。

👉 **使用網址：https://ericckfeng.github.io/jjcat/**

## 功能

- **快速記錄**：手打熱量、外食快選一鍵加入、拍照佐證、「暫估待修」之後再對照照片修正
- **份量估算**：自助餐／家常菜用手掌法則點選份量，自動算出熱量、蛋白質／碳水／脂肪與六大類份數（國健署食物代換表）
- **營養師目標**：每日熱量、三大營養素、六大類份數、目標體重
- **身體數據與每日備註**：體重、腰圍、喝水、運動、飢餓感、心情、排便、備註、「想問營養師」
- **趨勢**：7／14／30 天熱量與體重圖、營養素與六大類平均
- **營養師報告**：選期間 → 產生報告 → 列印存 PDF、分享報告檔，或複製文字摘要貼到 LINE
- **備份**：完整 JSON 備份（含照片）、匯入合併、CSV 匯出（可用 Excel 開）
- 可「加入主畫面」當 App 用，離線也能開

## 資料與隱私

- 所有記錄只存在**你自己手機的瀏覽器裡**（localStorage＋IndexedDB），不會上傳到 GitHub 或任何伺服器。
- 這個 repo 是公開的，但裡面只有程式碼，沒有任何個人資料。
- 換手機、清除瀏覽器資料前，請先到「報告」頁下載完整備份，再到新手機匯入。
- iPhone 建議一定要「加入主畫面」：Safari 對沒加入主畫面的網站，可能在一段時間沒開後清掉資料。

## 安裝到手機

- **iPhone**：用 Safari 開網址 → 分享 → 加入主畫面
- **Android**：用 Chrome 開網址 → 右上選單 → 安裝應用程式／加到主畫面

## 檔案結構

```
index.html            畫面
css/app.css           共用樣式與列印樣式
js/app.js             主要邏輯
js/report.js          營養師報告
js/nutrition.js       餐別、營養素、六大類代換、預設快選
js/db.js              照片儲存（IndexedDB）
sw.js                 離線快取
manifest.webmanifest  App 名稱與圖示
```

修改後直接 push 到 `main`，GitHub Pages 約 1 分鐘內更新；手機上關掉 App 重開即可拿到新版。

## 備註

外食熱量為一般份量參考值（來源列在 App 右上角 ⓘ），營養素與份數為自行估算，僅供和營養師討論參考。
