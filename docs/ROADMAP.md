# 改進構想（ROADMAP）

討論用的清單，不是承諾。做之前先跟使用者確認範圍；動到資料格式要先讀 `DATA_FORMAT.md` 的相容性規則。

## 原則（所有構想都要符合）
- 長輩好用：大字、大按鈕、一頁只做一件事，不把功能塞回首頁。原本「常吃清單按一下就記」的簡單流程一定保留，新功能是另一條路。
- 純前端、沒有後端。
- 使用者資料不送第三方。**例外（2026-11-18 決定）**：AI 辨識由使用者自己在設定開啟、用自己的 Gemini API Key，預設關閉；條碼查詢只送出條碼號碼。兩者都要在畫面上和 `privacy.html` 說明。
- 既有資料不能壞：只加欄位，不改名、不刪。

## 已決定的事（2026-11-18）
- **API Key 只存本機**（`meta`），不進同步檔、不進備份檔；每台裝置、每個人各自設定。要有測試確認匯出檔裡沒有 Key。
- **AI 分兩處**：
  - 主程式內（設定開啟，預設關閉）：(A) 拍餐點／一句話拆成品項放進購物車、(B) 拍包裝營養標示。附大字教學頁：到 Google AI Studio 按「Get API key」建立、貼回 App；說明免費、不用綁卡、免費方案資料可能被 Google 用來改進模型、Key 只存在這台手機；進階可限制 Key 只能用在 `https://ericckfeng.github.io/*`。
  - **另一個獨立小工具**：(C) 拍書頁表格批次建檔，匯出食物 JSON，主程式用「匯入自訂食物庫」讀入。兩者靠食物 JSON 格式交接，**不共用 localStorage**（同網域技術上可以，但寫壞會弄壞 `diet_tracker_v2`）。
  - 書本營養表有著作權：可個人匯入或由營養師分享 JSON 檔，不放進公開的內建資料庫；內建資料只用 TFDA 等開放授權來源。
- **小芽當寵物貓**：名字仍叫「小芽」，造型改成小貓。依狀態換表情／動作（喝水達標、蛋白質達標、睡飽、睡太少打瞌睡、聚餐後吃飽圓滾滾），點牠會有反應；提醒一天有上限、語氣不責備；可自訂語錄；累計減重里程碑（例如 -1kg ＝ 少背 2 瓶大寶特瓶）。不另外新增角色。
- **熱量銀行要做**，設定裡開關，預設關閉。

## 建議順序

### 0. 同步相容性（必須最先、單獨發佈）
- 問題：`mergeData()` 只回傳固定幾組資料，舊版 App 同步時會把不認得的**最上層資料**（例如自訂食物庫、套餐）丟掉再上傳，造成雲端和其他裝置的資料消失。
- 做法：讓 `mergeData` 保留未知的最上層資料（陣列以 `id`＋`updatedAt`＋tombstone 合併，物件以修改時間比較），補單元測試和新版備份檔樣本，更新 `DATA_FORMAT.md` 的規則 5。
- 這版發佈後，**等使用者裝置都更新**，才發佈會寫入新最上層資料的功能。
- 另外注意：舊版存「每日目標」會重建整個 `targets` 物件，新欄位會被洗掉。新欄位設計成「沒有＝手動／已鎖定」就安全。

### 1. 一鍵記一整餐
- 「套餐」：把常一起吃的品項存成一組，按一下整組記入，記入前可微調單項克數。
- 各餐別旁「複製昨日同餐」。
- 資料：新增 `combos`（要同步、要 tombstone、要 `updatedAt`），`mergeData` 要補測試。

### 2. 食物資料庫＋克數換算＋購物車
- 食物格式（欄位名配合現有程式）：
  `{ id, name, aliases[], category, per100g: { kcal, p, c, f }, serving: { g, label }, exPer100g: { grain, prot, veg, fruit, dairy, oil }, tip, updatedAt }`
  - 生熟重換算係數只在食物有定義時才出現切換；優先直接收錄熟食品項（白飯、雞胸肉（熟））。
- 內建 TFDA「食品營養成分資料庫」整理成精簡 JSON（離線可用、加進 `sw.js` 的 `CORE`；注意檔案大小與授權標示）。數值一律取自資料庫，不自己估。
- 台灣食材同義詞表（地瓜＝甘藷、花椰菜＝青花菜、芭樂＝番石榴、豆漿＝豆奶…）＋模糊搜尋；早上 05:00–10:30 早餐食材排前面。
- 克數輸入即時算出熱量、P/F/C、六大類份數；快捷鈕（+1 份、半碗 100g、一碗 200g、1 湯匙 15g）。
- 購物車：連續加入多個品項，底部顯示本餐總計，一次儲存。**每個品項各存一筆 Entry**，新增 `grams`、`foodId`、`groupId` 欄位（舊版、報告、CSV 都能照讀，不用改合併規則）。可存成套餐。
- 個人食物庫 `customFoods`（同步）；匯入／匯出 JSON：可勾選分類匯出成分享檔，匯入可選「只新增不重複」或「更新同名數值」。

### 3. 營養師目標、小芽寵物化、健康連動
- 營養師的目標：每天青菜幾份、每餐蛋白質幾份等；首頁／小芽提醒還差什麼；報告對照目標。
- 依最新體重試算目標（Mifflin-St Jeor；`profile` 新增 `birthYear`）：赤字 -300／-500、蛋白質 1.2／1.6／2.0 g/kg、脂肪 0.8 g/kg、碳水回推、喝水 35 ml/kg（有運動加碼）。**預設為鎖定（營養師的數字）**，使用者選了才自動計算；手動改過就鎖定，按「依目前體重重新試算」才重算。
- 小芽寵物貓（見上方決定）。
- 體重圖：保留每日圓點，加 7 日移動平均線。
- 跨模組提醒（都寫成純函式＋測試）：
  - 昨天高熱量且今天體重升 ≥0.5kg：溫和說明是水分與鈉滯留，不用紅字。
  - 昨晚睡不到 6 小時：提醒吃足蛋白質與蔬菜，喝水目標 +200ml。
  - 連 2 天排便 0 次（`bowel` 只記次數）：看近兩天蔬菜份數和喝水量給建議。
- 報告頂端自動產生 4～5 條本週重點。
- 週報：小芽整理「做得好的事」和「下週可以試的一件事」，可傳 LINE。
- 連續記錄天數與小成就（`buildMascotMessages` 是純函式，好寫測試）。

### 4. 進階功能（設定開啟，預設關閉）
- **熱量銀行**：週預算＝每日基準 × 7，首頁顯示進度；超標或少吃的差額平均攤到本週剩下的天數。安全底線：今日建議不低於 BMR 或 1,200 kcal，下修時蛋白質不減，只扣碳水和油脂。
- **AI 辨識 (A)(B)**：照片在前端壓到長邊 1024px，`gemini-2.5-flash`＋JSON 回應；一句話可用語音輸入（Web Speech API `zh-TW`）。(B) 結果可勾選存入個人食物庫。
- **AI 建檔小工具 (C)**：獨立程式，輸出食物 JSON。
- **條碼掃描**：`BarcodeDetector`（iPhone 不支援）→ 先查個人食物庫 → 再查 Open Food Facts → 存入個人食物庫。台灣商品資料少，查不到時引導手動輸入營養標示（有開 AI 才提供拍標示）。
- **桌面捷徑**：`manifest` shortcuts（只有 Android 支援），用網址參數（例如 `?go=water`）開對應的 `scr-*` 畫面。

### 其他（未排序）
- 血壓、血糖記錄：每日欄位，用 `setDayField`；血糖一天可能多次（空腹／餐後），要想資料形狀；趨勢圖和報告加欄位。
- 備份提醒：沒開雲端同步的人，超過 14 天沒匯出就提醒一次。

## 目前不做
- 固定時間推播提醒：需要伺服器。
- 開發者提供 AI 服務或共用 Key：會產生費用，也會讓使用者資料經過開發者。
